# Product

## Platform

web

## Users

複数の組織・コミュニティを横断して利用される。特定の1社に閉じた前提ではなく、
実運用でも `outlook.com`/`hotmail.com`/`gmail.com` など個人向けメールプロバイダのアドレスで
登録できる設定になっている(特定の1社の企業ドメインに限定されていない)。
主な利用者は Claude Code などのAIツールを日常的に使い、スキル(SKILL.md)・プロンプト・
役立つOSSの情報を「投稿して共有したい人」「探して再利用したい人」の両方。

## Product Purpose

AIノウハウ・ナレッジ共有サイト。Claude Codeのスキルやプロンプト、便利なOSSの紹介を
投稿・検索・再利用できるようにすることで、AI活用のノウハウが個人やチームの中に
埋もれず、組織・コミュニティ内で蓄積・流通する状態をつくる。
成功は「投稿されたノウハウが実際に検索され、DL・コピーされ、使われ続けること」であり、
利用数ランキング(累計・過去7日・過去30日)で可視化される。

## Positioning

核心は「AIノウハウを蓄積・検索・再利用できるナレッジサイト」であること。
MCP(Model Context Protocol)対応はサイトが提供する数ある利用経路・機能の一つであり、
差別化のポイントとして押し出すものではない(ユーザー確認済み)。
外部IdPに依存しない自前のメール+パスワード認証で自己ホスト運用できる点、
タグ・検索・利用数ランキングでノウハウの発見性を高める点が特徴。

## Operating Context

- 投稿種別: スキル(ZIPまたはSKILL.md単体アップロード)/ プロンプト(テキスト)/ OSS紹介
  - SKILL.md選択時はフロントマター(`name`/`description`)と本文からタイトル等を自動入力
  - OSS紹介はGitHubのURL入力でタイトル・概要・作者・ライセンスを自動取得可能
- 投稿の編集・削除は投稿者本人のみ
- タグ機能: デフォルトタグ + 投稿者による新規タグ追加、複数タグでのAND絞り込み
- タイトル・説明文の部分一致検索
- ソート: 新着順 / 利用数順(DL数・コピー数) / お気に入り数順 / 名前順
- お気に入り登録・お気に入り一覧
- プロンプトはワンクリックでクリップボードコピー、または本文入力済みでclaude.aiの
  新規チャットへ遷移。スキルはブラウザから直接ダウンロード
- ユーザープロフィール(表示名・姓名・会社名・役職・部署・従業員の種類)は誰でも閲覧可能、
  本人のみ編集可能
- MCPサーバー(`/api/mcp`)経由で、Claude Code/Claude Desktop等から検索・新規投稿・編集・
  お気に入り登録が可能。認証は個人アクセストークン(`/settings/tokens`で発行)
- 使い方ガイド(`/guide`)をフッターから常時参照可能

## Capabilities and Constraints

- 会員登録範囲は運用者が「誰でも登録可」/「特定ドメインのみ」を設定で切替可能。
  実運用の `wrangler.jsonc` を確認したところ `REGISTRATION_MODE=domain_restricted`
  (`ALLOWED_EMAIL_DOMAINS=outlook.com,hotmail.com,gmail.com`)で、特定の1社ドメインではなく
  主要な個人向けメールプロバイダ数種に限定する運用になっている(2026-09-25確認)
- パスワードはPBKDF2-SHA256でハッシュ化。セッションはD1管理のランダムトークン方式
  (JWTではない)で、ログアウト・パスワード変更時に即座に失効可能
- メール送信はResend / Cloudflare Email Serviceを設定で切替可能
- ライト/ダークテーマ切替に対応済み(OS設定検出 + 手動切替)

## Product Principles

- ノウハウの発見性を最優先する: タグ・検索・ランキングで「使われているものが見える」状態を保つ
- 投稿のしやすさを重視する: SKILL.mdのフロントマター自動入力やGitHub URLからのOSS情報自動取得など、
  投稿の手間を減らす工夫を優先する
- 自己完結・低依存を保つ: 外部IdPに依存しない自前認証、Cloudflareスタック内で完結する自己ホスト運用
- 特定組織に閉じない前提で設計する: 複数組織・コミュニティ横断の利用を想定し、
  特定の1社向けの固有表現・偏った例示を避ける
